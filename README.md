## HaloBar

Battery, Wi-Fi and cellular signal in a customizable ring.

- Arabic and English settings.
- Live preview and independent Wi-Fi / 5G controls.
- Matching colors for the clock and indicator.
- Charging appearance and transition controls.

Target: iOS 16 rootless jailbreaks. Development setup: iPhone 14 Pro, iOS 16.4.1, Dopamine.
